# 🥋 Codewars — JavaScript

Repositório dedicado à resolução de desafios de programação da plataforma [Codewars](https://www.codewars.com/), utilizando **JavaScript**.

## 🎯 Objetivo

Praticar programação regularmente, aprimorar o raciocínio lógico e desenvolver habilidades em JavaScript por meio de desafios com diferentes níveis de dificuldade.

## 🛠️ Tecnologias

- JavaScript (ES6+)
- Node.js
- Git e GitHub

## 📚 Conteúdos praticados

- Lógica de programação
- Arrays e Strings
- Funções e métodos
- Manipulação de objetos
- Algoritmos e estruturas de dados
- Programação funcional

## 📈 Progresso

Os desafios são organizados conforme sua dificuldade, seguindo o sistema de classificação do Codewars, de **8 kyu (iniciante)** até **1 kyu (avançado)**.

## 🚀 Executando os desafios

Com o Node.js instalado, execute:

```bash
node nome-do-arquivo.js
```
